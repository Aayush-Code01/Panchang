# Shubhly

Shubhly (formerly Panchang): your day, well timed. A daily panchang web app: day mood, good and avoid times, practice and mantras. Calculated on the device with [astronomy-engine](https://github.com/cosinekitty/astronomy) (MIT).

Moon image: near-side projection of the lunar surface map from the three.js examples (MIT), based on NASA imagery.
